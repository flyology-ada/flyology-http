# Flyology HTTP website design

## Relationship

The site is a sibling of flyology.org and postgres.flyology.org. It uses the
shared Flyology website kit, Geologica typeface, mark, spacing, navigation,
light/dark themes, and precise mechanical register.

## Distinctive idea

The main page presents the library as two directions through one protocol:
outbound client requests and inbound server exchanges. Diagrams use bounded
nodes and directional connectors. Documentation splits those directions into
separate client and server guides.

## Visual rules

- Use the Flyology navy, violet, coral, and teal palette without gradients.
- Prefer open sections, rules, and process diagrams over card grids.
- Keep code examples functional and syntax-highlighted.
- Use modest factual copy and keep limits beside capabilities.
- Avoid glass effects, floating decorative shapes, gradient text, and slogans.

## Accessibility and behavior

The shared kit supplies the responsive navigation, focus states, theme toggle,
code-copy controls, and Ada syntax highlighting. Pages retain a skip link,
semantic headings, descriptive navigation labels, and reduced-motion support.
